# HuangQiang-Paper-Checklist

记录黄强导师的历史论文要求，作为按需使用的参考。它们不保证适用于每个模板，也不代表已经完整、准确地概括老师当前的偏好。

## 适用原则

- 用户当前要求和老师最新的明确意见优先于本清单。老师刚修改过的源码和布局是当前任务的重要依据，不为满足旧清单而机械改回去。
- 用户要求处理某条直接意见时，只处理该问题及必要的配套修改；只有请求全面检查时才逐项审查。编译和查看受影响页面用于验证本次改动，不自动扩大为全篇格式整改。
- 不为满足历史记录中的固定宽度、间距等数值而增加复杂封装或局部补丁。尤其第 10、13 条应结合模板现有间距和实际表宽理解；老师的最新调整优先。其他旧条目在未得到新意见前保留为参考，不自行推断它们全部失效。

## 十七项规则

1. **公式索引用 `\in` 加集合写法。** 例如将 `i=0,\ldots,P-1` 写为 `i \in \{0,\cdots,P-1\}`。保留原索引范围与数学含义；此规则针对索引取值范围，不改写普通等式或求和上下限。

2. **内部交叉引用与论文引用使用不同颜色，内部交叉引用优先用紫色。** 在现有 `hyperref` 配置中设置 `linkcolor=purple`，并确保 `citecolor` 与其不同；保留已有合适的文献引用色和 URL 色。例如已有文献引用色为 `deepblue` 时：
   ```latex
   \hypersetup{linkcolor=purple, citecolor=deepblue}
   ```

3. **页顶或页底浮动图表与正文之间的间距，默认参考 `\textfloatsep=1.25em`。** 图和表共用此设置，在导言区或统一排版配置中设置：
   ```latex
   \setlength{\textfloatsep}{1.25em}
   ```
   检查模板和后续局部设置是否覆盖该值，避免仅放在某张表之后而只影响后续内容。它不统一控制所有图表前后间距：正文中间的浮动体使用 `\intextsep`，相邻浮动体之间使用 `\floatsep`；caption 与图表主体的间距另行控制。双栏跨栏浮动体还涉及 `\dbltextfloatsep` 和 `\dblfloatsep`。沿用老师最新的间距调整，不为参考值机械覆盖现有设置。

4. **表格行距按表局部设置，不要求全局设置 `\arraystretch`。** 行距系数通常参考 `1.1` 或 `1.2`，空间紧张时参考 `1.05`。需要调整时，在相应表格环境或局部分组中设置：
   ```latex
   \renewcommand{\arraystretch}{1.1} % 更宽松时用 1.2，空间紧张时用 1.05
   ```
   保留老师最新的逐表设置，例如长文本表使用 `1.3` 或 `1.4`，不要为统一数值而改回。未显式设置的表格沿用模板或 LaTeX 默认值。不要据此擅自将正文改为 `\linespread{1.1}`、`\linespread{1.2}` 或相应倍数行距；用户明确要求正文行距时按其指示处理。

5. **纵向间距调整一律使用 `em` 作为单位。** 包括 `\vspace`、`\vspace*`、`\vskip`、换行后的额外间距（如 `\\[0.5em]`），以及浮动体、标题、段落、公式等纵向间距的显式设置；正负间距均适用。不要使用 `pt`、`ex`、`mm`、`cm` 或 `\baselineskip` 倍数表达这些调整；弹性间距的 `plus`、`minus` 部分也使用 `em`。例如使用 `\vspace{-0.5em}`。转换已有设置时，依据生效位置的字号和实际长度换算并检查排版，不直接保留原数值替换单位。此规则针对显式纵向间距调整；横向间距和无量纲的 `\arraystretch` 系数不受影响。

6. **重点要求：表格列格式简洁、直观，优先显式列声明。** 优先使用 `\begin{tabular}{ll ccccc ccccc c}` 这类一眼可见列数和对齐方式的写法。避免不必要的竖线、重复列语法、边距控制及混合列修饰，例如 `\begin{tabular}{@{} l l|*{6}{r}r|*{3}{r}r|r @{} }`。通常文本列左对齐、数值列居中；只有具体排版需要时才保留 `@{}`、`*{n}{...}` 或其他特殊列格式。长文本需要换行时可用明确宽度的 `p{...}`。示例仅表示风格，不是固定列数模板；修改时按实际表格保留列数、分组与 `\multicolumn` 跨列关系，并检查宽度和对齐。

7. **所有表头字体统一加粗。** 包括每一级列标题、分组表头，以及承担表头作用的行标题；`\multicolumn` 和 `\multirow` 中的表头也须加粗。普通文字使用 `\textbf{...}` 或局部 `\bfseries`；数学表头使用合适的数学加粗命令（如 `\boldsymbol{...}` 或 `\bm{...}`），确保希腊字母等符号实际呈现粗体。加粗范围限于表头，不自动扩展到普通数据单元格；caption 按第 11 条处理。

8. **普通公式尽量使用默认尺寸括号，避免不必要的 `\left...\right`。** 除非括号内含 `\sum`、`\frac` 等较高结构且确需放大，否则优先使用普通的 `(...)`、`[...]`、`\{...\}`。不要仅因变量有上下标、粗体或波浪号就自动放大括号，也不要机械改成 `\big`、`\Big` 等大号括号。是否需要放大应结合实际显示高度判断；出现求和或分式并不意味着必须放大。ShallowStream 的 `eqn:full_depth_generation`（提出此要求时为公式 15）是反例：`Compose`、`F^i` 和条件概率的外层括号不应默认使用 `\left...\right`；例如优先写 `F^i(\widetilde{\bm{H}}^i)`。修改时保持括号配对、分组和数学含义不变，并检查最终公式显示。

9. **数字枚举中的省略号统一使用 `\cdots`。** 例如写作 `0,1,\cdots,P-1`、`\{1,2,\cdots,N\}`，不用 `\ldots`、`\dots` 或直接输入的 `...`、`…`。索引范围同时遵守第 1 条，例如 `i \in \{0,\cdots,P-1\}`。保留原枚举的起止值、步长与数学含义；此规则不要求替换普通叙述文字中的省略号。

10. **表格 caption 与表格顶部之间保留适当间距。** 对上置 caption，在 caption（及其 `\label`）之后、表格主体之前适当留白，默认参考 `\vspace{0.5em}`，避免标题紧贴表格顶线。若模板或统一 caption 配置已经提供相当的间距，不重复叠加；以最终 PDF 的实际效果为准，并保持全篇一致。间距统一使用 `em`，此处调整的是 caption 与表格主体之间的距离，不是浮动体与正文之间的 `\textfloatsep`。

11. **每个 figure 和 table 的 caption 第一句应概括图表内容，并加粗。** 首句说明图或表整体展示什么；如需解释细节，放在后续句子中。只加粗第一句，不将整个 caption 一并加粗。例如：`\caption{\textbf{Comparison of decoding throughput across methods.} Higher is better.}`。对 `figure*`、`table*` 及围绕式图表的 caption 同样适用；保留原有信息和 `\label`，不要为满足格式而删去必要说明。

12. **附录中的每个大节（`\section`）都应在正文中有对应引用，不要求每个小节（`\subsection`）都有引用。** 在正文讨论相关方法、实验或分析时，用 `\ref`、`\cref` 等交叉引用指向相应附录大节，并说明其提供的内容。小节按实际需要引用，不逐一强制补齐。附录内部互引不能替代正文对大节的引用，也不要为了满足规则堆放没有实际作用的引用。

13. **非围绕式图表的主体宽度使用 `0.99\textwidth`。** 普通图片可用 `\includegraphics[width=0.99\textwidth]{...}`。普通数值表优先保留简洁列声明，用 `\resizebox{0.99\textwidth}{!}{...}` 调整整表宽度。长文本表先考虑 `tabular` 配合明确宽度的 `p{...}` 列；确需自动分配剩余列宽时再使用 `tabularx`，并检查文字可读性。并排图表用 `minipage` 时，使整组约占 `0.99\textwidth`；每个 minipage 内的表格可用 `\resizebox{0.99\linewidth}{!}{...}` 贴合各自栏宽。`wrapfigure`、`wraptable` 按围绕区域的局部 `\linewidth` 排版，不强行扩大到正文宽度。修改后检查图表比例、文字可读性和实际分页。

14. **所有 Figure 的排版代码直接写在所在章节 `.tex` 中，Table 的源码集中分文件管理。** 正文图写在对应正文章节，附录图写在对应附录章节。`figure`、`figure*`、`wrapfigure`、并排图的 `minipage`、caption 和 label 全部直接写在该章节中，不为 Figure 另建排版 `.tex` 文件，不通过 `\input`、`\include`、自定义钩子或宏间接引入。表图共用一个浮动体时，整组代码也直接写在章节中。图片 PDF/PNG 等素材仍放在 `figures/`，直接用 `\includegraphics` 引用；独立生成图片素材的绘图脚本不属于章节排版代码。

    正文表格放在 `tables/`，附录表格放在 `appendix_tables/`。每张表的 `table` 环境、caption、label、表头和数据放在同一个表格文件中，章节 `.tex` 直接通过 `\input{...}` 引用，使老师从引用处跳转一次就能找到整张表。避免表格文件再通过 `\input` 或 `\include` 引用表头、数据或子表片段。并排且独立编号的表格共用一个浮动体时，外层 `table` 和各表的 `minipage`、caption、label、表头及数据集中在同一个组合文件中，不再拆成多层文件。移动已有图表排版代码时保留内容、标签和布局参数，并更新所有生效的引用路径。

15. **表格源码优先简单、直接、容易定位，源码文件引用链不得超过 4 层。** 按 `\input`、`\include` 的文件引用链计层，主文件为第 1 层；通常采用“主文件 → 章节 → 完整表格”即可。避免一个表格 `.tex` 再拆分引用多个表头、数据或子表文件。文件引用层数与单元格内部的表格环境嵌套分别判断。

    - 优先使用 `tabular`，尽量减少 `tabularx`。数值表和可用简单 `p{...}` 列表达的长文本表优先采用 `tabular`；确实需要自动分配剩余列宽时才保留 `tabularx`。不为替换已有 `tabularx` 而增加复杂列格式或破坏现有布局。多行表头、分数及其差值尽量写成普通表格行，避免不必要的单元格内嵌套 `tabular` 或隐藏内容的自定义宏。
    - 不为静态结果表建立包含条件判断、动态字号、局部行距和偏移的复杂排版宏。简单数据和正负差值直接写明；确有复用价值的简单宏可以保留。
    - 统一重复的颜色和通用样式定义，删除废弃的排版分支、注释掉的旧补丁及无效的重复设置。必要的数据来源说明应保留。
    - 优先利用模板和标准表格命令提供的布局；避免空白占位列、负间距、反复缩放和多处字号调整互相补偿。保留确有必要的单层 `resizebox`、长文本自动换行或围绕式布局，不为追求代码行数少而破坏可读性。
    - 按第 14 条集中表格源码，检查章节到完整表格的引用路径，避免为表头、数据或并排子表增加多层文件跳转。章节直接引用完整表格文件、同一文件内必要的并排 `minipage` 可以保留。
    - 简化时保留表格数据、差值符号、行列对应关系、caption 和 label。尽量沿用老师最新的布局，只做完成简化所需的调整。

16. **禁止使用 `\FloatBarrier`。** 让图表浮动与后续正文自然排版，不用该命令强制先排完前面的图表再继续正文，以免造成大块留白或将后续章节推到下一页。检查现有源码时移除该命令。

17. **禁止使用 `needspace`。** 不加载 `needspace` 宏包，不使用 `\needspace`、`\Needspace` 及其星号形式预留页内空间或强制分页。检查现有源码时移除相应命令和宏包加载，并查看受影响页面的自然分页。

## 验证

按本次任务范围选择下面的检查，不要求每次局部修改都执行全清单。表格源码简化后，逐行核对数据与差值、分组和引用标签，并编译查看受影响页面，确认没有错位、遮挡或新增溢出。不要仅凭编译成功认定简化正确。

同时检查表格 caption 与表格顶部是否留有适当且一致的间距，避免重复设置造成过大留白。

检查所有 Figure 的排版代码是否直接位于正文或附录的所在章节，包含表图混排和使用 `\captionof{figure}` 的图；移除外置图排版文件及其间接引用，同时保留图片素材和独立绘图脚本。

检查源码中是否存在生效的 `\FloatBarrier`；如有，按第 16 条移除，并检查受影响页面的正文衔接与浮动体位置。

检查是否加载 `needspace` 或使用 `\needspace`、`\Needspace`（含星号形式）；如有，按第 17 条移除，并检查受影响页面的分页。

修改后核对源码中的生效配置、纵向间距是否统一使用 `em`、表格列声明是否存在不必要的复杂格式、所有表头是否加粗、每个图表 caption 的第一句是否具有概括性且仅该句加粗、公式是否使用了不必要的大号括号、数字枚举中的省略号是否统一使用 `\cdots`、非围绕式图表是否按 `0.99\textwidth` 排版、图表文件和 `\input` 路径是否符合第 14 条，并编译论文、查看受影响页面。同时逐一核对附录各 `\section` 的标签是否在正文中被有意义地引用，不要求各 `\subsection` 逐一被引用，检查围绕式图表及图注是否越界、表格宽度与对齐、行距和分页、链接颜色、公式括号大小。若只完成源码检查，明确说明尚未验证最终 PDF 排版。
