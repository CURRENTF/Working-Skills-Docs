# PPTX 编辑便利性

交付既能演示、又方便用户继续修改的 PPTX。与当前可用的 presentations 技能配合使用：制作工具、导出与文件校验遵循其流程，本技能补充对象粒度和编辑体验要求。不要为了应用本技能重做无关内容或更改用户选定的设计。

## 文本框按语义组织

- 页面标题及各独立区域的小标题单独成框；其下的连续正文另用一个文本框，不为了合并而将标题塞进正文框。同一区域的多个正文段落、列表和相关数字应能连续增删和重排，不因自然段不同而拆框。
- 用原生段落、适度的段前/段后间距或必要的空行分隔正文；不要为了固定各段纵坐标而分别创建文本框，也不要用重复空格对齐文字。
- 页面标题、页脚、独立图注，以及分属不同布局区域（例如左右两列）的内容可以独立；独立动画或确实需要单独定位的内容也可分开。不要把“每个段落一个文本框”当作默认规则，也不强行将整页所有文字合成一个框。
- 同一列表通常放在一个框内，以原生段落、项目符号及缩进控制层级。分属不同布局区域或需要独立动画的条目可以分开。
- 同一行内的数字、单位、加粗词和链接优先使用同一文本框中的富文本 runs。字号或颜色不同不是拆框的理由。
- 不把逐行文本框组合成 group 后宣称已支持整段编辑。组合只方便整体移动，不能让文字连续增删和重排。
- 用户明确要求逐字动画、独立定位标签等效果时，允许相应拆分；不要把例外扩展到普通正文。

例：“预训练数据质量评估”标题单独一个框；其下关于质量维度、消融实验、轻量化探索的三段正文共用另一个框，使用适度段间距或必要空行分隔。即使某段显示多行，也不能按视觉行拆框。

## 换行与版式

- 普通正文优先采用自动换行，框宽、字号、行距和内边距共同决定排版。不要逐字符插空格或零宽字符来控制换行。
- 中文文字及其标点明确设置简体中文语言标记（如 `a:rPr/@lang="zh-CN"`），段落默认文字样式也设置对应语言；独立英文 run 可标记 `en-US`。仅指定中文字体或设置 `eaLnBrk`，不代表 PowerPoint 会对缺失语言标记的文字正确应用中文禁则。
- 出现顿号、逗号等落在行首时，先排除手动换行，再检查文字语言及“使用中文版式规则”，必要时检查演示文稿的禁则字符表。在副本中改变文本框宽度，验证原生 PowerPoint 仍能自动避开非法行首；不以固定换行、插入隐形字符或碰巧合适的框宽掩盖问题。
- 行距和段间距按阅读节奏设置，不按可用框高均匀拉伸。不为填满页面或对齐底边而设置过大的行距、段间距或堆叠空行；内容较少时允许保留空白，正文优先顶部对齐。
- 只有明确的语义分段或有意固定的短标题才需要手动换行。不要把网页当前每一行都固化为段落分隔符，导致用户改宽度或增删文字后无法自然重排。
- 为正文的合理小幅增改预留空间。出现溢出时调整局部布局或文本框尺寸，不以逐行拆框或整页栅格化解决。
- 同一框内先设基础样式，再应用局部富文本样式；检查后续全框样式赋值是否覆盖了数字单位、加粗或字号差异。

## 字重与格式继承

- 制作可继续编辑的文字时，正文段落和列表级别默认使用常规字重，强调放在文字 run 的显式 `b="1"` 属性上。不要用段落或列表的默认加粗承载局部强调，否则编辑器取消文字加粗时可能回退到上层粗体。
- 遇到“无法取消加粗”时，检查文字 `a:rPr`、段落 `a:pPr/a:defRPr`、文本框 `a:lstStyle` 以及相关版式/母版的继承链，同时排查字体名称是否直接指定 Bold/Semibold 等字重。用户要求整份检查时，扫描所有页面，包括标题、列表和表格，不只修复截图中的对象。
- 修复前先解析现有有效字重，将需要保留的强调显式写到对应 run，再清理导致回退的默认粗体；检查 `a:endParaRPr`，避免续写继续带入非预期粗体。保留文字、其他格式、布局与原有强调，不把全部文字一律改成普通字重。只有确实来自共享版式/母版的问题才修改共享层，并检查所有受影响页面。
- 验证既要对比修复前后渲染，也要在副本中检查移除或关闭 run 加粗后是否回到常规字重。XML 中不再有隐式粗体仅能证明继承关系已修复；未在 PowerPoint 中操作时，不声称已验证应用内切换行为。

## 从 HTML 或其他格式转换

- 从语义结构提取标题、段落、列表、表格和图注。DOM Range 或字符边界可用于测量与诊断，不能直接把每个视觉行或每个字符导出为独立 shape。
- 网页坐标只是布局参考。浏览器与 PPTX 渲染器的字体、行高和中英文断行可能不同，需要调整原生排版。
- 原生表格保持单元格可编辑。数据图表保留可编辑序列及所需嵌入工作簿，不用截图替代。
- 官方架构图、产品截图等原始图片可以作为图片嵌入，无需为了“全可编辑”臆造其内部对象。用户要求本地图片时下载并嵌入，避免外链依赖。
- 保留讲者备注、图源、统计口径及必要的事实限定。格式转换不等于重新核验了原材料中的全部事实。

## 验证编辑体验

根据修改范围做针对性检查，不能只看截图：

1. **结构**：确认标题与正文分框，同一区域的多个正文段落位于一个文本框中，以原生段落组织；未按段、按行过度拆成多个 shape，也没有用对象组合掩盖拆分。可以检查 OOXML 或对象树。
2. **重排**：在临时副本中给内容块的前一段增添少量文字或调整框宽，检查其后的段落能否在同一文本框内自然后移，以及与邻近元素的关系。有实际应用可用时优先检查原生编辑行为；仅检查 XML 不能声称完成了应用内编辑验证。
3. **视觉**：检查改动页的遮挡、截断、异常中英文断行、局部富文本样式，以及是否存在为填满空间而拉大的行距或段间距。全新转换检查整份演示。
4. **证据边界**：截图显示正常不证明整段可编辑，结构校验通过也不证明 PowerPoint 显示正常。渲染器缺字体时先排查字体配置，不把工具故障误当成必须拆框的理由。
